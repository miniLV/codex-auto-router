# Recheck Expected Sol Work Reduction before correction

Status: Superseded by the current Runtime Router Policy.

Before each Focused Correction, Root re-evaluates the remaining Expected Sol Work Reduction. The record includes another Worker dispatch, Root Verification and Finalization, a fresh semantic review, and likely recovery. If avoided Sol work no longer exceeds added Sol work—or the comparison is materially uncertain—the delegation lane ends early and Root takes over rather than consuming the full three-round ceiling.

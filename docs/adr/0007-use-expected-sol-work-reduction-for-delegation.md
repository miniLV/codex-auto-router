# Use Expected Sol Work Reduction for delegation

Status: Superseded by the current Runtime Router Policy.

No trustworthy per-task Credit source is available to this contract. Delegation therefore requires a structured Expected Sol Work Reduction record comparing bounded Root-direct Sol work avoided with added packet preparation, Root verification/finalization, Fresh Review, and likely recovery work. Missing or incomparable terms fail closed. This is qualitative evidence, not a fabricated numeric Credit value. Dashboard, `ccusage`, `src/credit.ts`, and latency are not routing inputs; latency remains a separate constraint.

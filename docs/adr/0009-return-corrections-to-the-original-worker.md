# Return corrections to the original Worker

Status: Superseded by the current Runtime Router Policy.

A bounded correction returns to the original Worker with a corrected specification and consumes the next Delivery Round when runtime probe P4 proves same-child continuation. Reusing the Worker preserves context and ownership. If it is unavailable or unproven, Root takes over; the only exception is the single fresh Terra option after Root resolves Luna, using the remaining shared budget.

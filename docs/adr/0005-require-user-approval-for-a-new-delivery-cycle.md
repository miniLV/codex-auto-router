# Require user approval for a new Delivery Cycle

Status: Superseded by the current Runtime Router Policy.

Architectural reconsideration or exhausted Delivery Budget terminates the delegation lane, not the original user goal. Root adopts or restores the current change set and may finish the original authorized scope directly without new approval. Materially expanding scope, adopting a new architecture, or starting a new automated Delivery Cycle requires explicit user approval, preventing an implicit budget reset.
